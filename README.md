# ExamGuard

ExamGuard는 학교·자격 시험장의 공정성을 위해 공익 목적으로 공개하는 오픈소스 앱입니다. 상용 판매를 하지 않으며, 감독관 휴대폰 한 대로 숨긴 무선기기의 위치를 자리 단위로 좁혀 줍니다.

### 기능

| 기능 | 하는 일 | 지원 |
| --- | --- | --- |
| 기준 등록 | 빈 교실에서 15초 스캔해 감독관 폰·공유기 같은 상시 기기를 제외 목록에 저장 | Android, iOS |
| 책상 배치 설정 | 행·열 수와 책상 간격을 입력하면 A-1, B-3 같은 자리 이름이 붙은 맵 생성 | Android, iOS |
| 걸음 기반 위치 추적 | 가속도 센서로 걸음, 자이로로 방향을 계산해 원점 기준 감독관 좌표를 실시간 추적 | Android, iOS |
| BLE 스캔 | 이어폰·안경·워치·폰의 광고 신호를 받아 이름과 제조사 코드로 종류 분류 | Android, iOS |
| Wi-Fi 스캔 | 숨긴 폰의 핫스팟·숨긴 SSID 탐지 | Android만 |
| 신호 히트맵 | 위치별 신호 세기를 기록해 기기 추정 위치를 맵 위에 색으로 표시 | Android, iOS |
| 패턴 분석 | 근접 피크, 지속성, 거리-세기 일치도를 합쳐 0~100점 의심 점수 계산 | Android, iOS |
| 경고 배너 | 60점 이상이면 "확인 필요: B-3 92%"처럼 자리 이름 표시, 근접 시 주황 경고 | Android, iOS |

### 패턴 분석 원리

1. **위치 추정:** 신호가 강하게 잡힌 지점일수록 무게를 크게 둔 가중 평균으로 기기 위치를 계산하고, 가장 가까운 책상에 매칭합니다.
2. **근접 피크(35%):** 감독관이 지나갈 때 기록된 최대 세기입니다. −50dBm 이상이면 1~2m 안에 기기가 있다는 뜻입니다.
3. **지속성(30%):** 최근 3분을 10초 구간으로 나눠, 신호가 잡힌 구간의 비율입니다. 시험 내내 켜져 있는 기기일수록 높습니다.
4. **거리-세기 일치도(35%):** 추정 위치에 가까워질수록 신호가 세지는지 상관계수로 봅니다. 한 자리에 고정된 기기면 높고, 지나가는 사람의 기기나 반사 신호면 낮습니다.
5. **종류 가중치:** 이어폰·안경 1.0, 폰·핫스팟 0.9, 워치 0.7, 미확인 0.4를 곱합니다.

### 설치와 실행

1. Flutter 3.x를 설치하고 이 저장소를 받습니다.
2. `flutter pub get` 후 Android는 `flutter build apk`로 APK를 만들어 바로 배포합니다.
3. iOS는 Xcode에서 서명한 뒤 TestFlight로 배포하면 정식 심사 없이 기관 내 설치가 가능합니다.

### 현장 사용 순서

1. 시험 전 빈 교실에서 [기준 등록]을 누릅니다.
2. 행·열을 실제 배치에 맞추고, 교탁 쪽 왼쪽 앞 모서리에 서서 폰을 교실 뒤쪽으로 향한 채 [원점에서 시작]을 누릅니다.
3. 통로를 따라 천천히, 폰을 가슴 높이에 들고 한두 바퀴 돕니다.
4. 빨간 배너에 뜬 자리를 조용히 확인합니다. 점수는 확인할 자리를 알려 주는 참고값이며, 부정행위의 증거가 아닙니다.

### 한계 (꼭 공개)

- 전원이 꺼진 기기, LTE로만 통신하는 장치, 이미 연결된 블루투스 통신 내용은 휴대폰으로 탐지할 수 없습니다.
- iOS는 Wi-Fi 스캔이 막혀 있어 BLE만 쓰고, BLE 주소가 주기적으로 바뀌어 같은 기기가 둘로 보일 수 있습니다.
- 걸음 추적은 오래 걸을수록 오차가 쌓입니다. 한 바퀴마다 원점에서 다시 시작하는 것을 권장합니다.
- 걸음 감지 기준(11.2m/s²), 보폭(0.65m), 경고 점수(60점)는 현장에서 보정이 필요합니다.

### 개인정보와 윤리

- 앱은 주변 기기가 공개로 내보내는 광고 신호만 수신하며, 통신 내용을 가로채거나 연결하지 않습니다.
- 스캔 데이터는 폰 안에만 있고 서버로 전송하지 않으며, 중지하면 지워집니다.
- 탐지 결과만으로 응시자를 처분하지 말고, 반드시 감독관이 직접 확인하도록 운영 규정에 명시하세요.
